# suggest (default)

> 판단이 필요하면 선택지를 제시하고 확인 후 진행한다.
> 기계적 작업만 자율 진행한다.

## 설정값

| # | 카테고리 | 능력 | 설정 | X일 때 행동 |
|---|----------|------|------|------------|
| 1 | 요구사항 해석 | 모호한 지시 해석 | X | 해석이 여러 개면 선택지 제시 |
| 2 | 요구사항 해석 | 범위 판단 | X | 포함 여부가 불확실하면 확인 |
| 3 | 요구사항 해석 | 암묵적 요구사항 추론 | X | 추론한 내용을 명시하고 확인 |
| 4 | 요구사항 해석 | 우선순위 결정 | X | 우선순위안을 제시하고 확인 |
| 5 | 기술 선택 | 도구/라이브러리 선택 | X | 선택지 나열 후 확인 |
| 6 | 기술 선택 | 아키텍처/패턴 선택 | X | 트레이드오프와 함께 제안 |
| 7 | 기술 선택 | 파일 구조/위치 결정 | X | 기존 패턴 기반 제안 후 확인 |
| 8 | 코드 실행 | 지시되지 않은 파일 생성 | X | 필요성을 설명하고 확인 |
| 9 | 프로세스 판단 | 워크플로우 단계 전환 | X | 완료 증거와 함께 전환 제안 |
| 10 | 프로세스 판단 | 장애물 우회 방법 결정 | X | 장애물 상태 + 대안을 보고 후 확인 |
| 11 | 프로세스 판단 | 작업 완료 판단 | X | 완료 기준 대조 후 확인 |
| 12 | 부수 작업 | 메모리 저장 | X | 저장 여부를 물어봄 |
| 13 | 부수 작업 | 관련 문서 업데이트 | X | 업데이트 필요성을 제안 후 확인 |
