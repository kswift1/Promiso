# Learning Profile

> 새 언어로 코드를 작성할 때, 익숙한 언어 기반으로 설명하는 방식을 제어한다.
> 프로필이 설정되지 않으면 설명 없이 코드만 작성한다.

## 프로필 전환

```
learner 프로필로 진행해
practitioner로 전환해
학습 프로필 만들어줘
```

---

## 고정값 — 직접 입력

프로필 설정 시 아래 두 항목은 유저가 직접 지정한다.

| 항목 | 설명 | 예시 |
|------|------|------|
| 익숙한 언어 | 설명 시 비교 기준이 되는 언어 | Swift, Python, TypeScript |
| 작성 대상 언어 | 이번 작업에서 작성하는 언어 | Rust, Go, Kotlin |

---

## 설정값 정의 — 5개

| # | 설정 | 선택지 | 설명 |
|---|------|--------|------|
| 1 | 익숙한 언어 숙련도 | 주니어 / 시니어 | 비교 설명의 깊이를 결정. 주니어면 기초 개념부터, 시니어면 차이점 위주 |
| 2 | 새 언어 경험 수준 | 입문 / 기초 / 중급 | 어디까지 설명할지 결정. 입문이면 기본 문법부터, 중급이면 고급 패턴만 |
| 3 | 비교 설명 범위 | 문법 / 문법+패턴 / 문법+패턴+생태계 | 문법: 구문 비교만. 패턴: 설계 패턴, 관용구 포함. 생태계: 라이브러리, 도구, 커뮤니티 관례 포함 |
| 4 | 설명 시점 | 항상 / 요청 시 | 항상: 코드 작성마다 비교 설명 포함. 요청 시: 유저가 물어볼 때만 |
| 5 | 설명 형식 | 코드 비교 / 텍스트 / 코드+텍스트 | 코드 비교: 양쪽 코드를 나란히. 텍스트: 산문 설명. 코드+텍스트: 코드 비교 + 해설 |

---

## 프리셋

| 설정 | **learner** | **practitioner** |
|------|-------------|------------------|
| 숙련도 | 주니어 | 시니어 |
| 새 언어 경험 | 입문 | 기초 이상 |
| 설명 범위 | 문법+패턴+생태계 | 문법+패턴 |
| 설명 시점 | 항상 | 요청 시 |
| 설명 형식 | 코드+텍스트 | 코드 비교 |

---

## 커스텀 프로필 생성 절차

유저가 "학습 프로필 만들어줘"라고 하면 아래 절차를 따른다.

### Step 1 — 고정값 입력

```
작성 대상 언어는 무엇인가요? (예: Rust)
설명 시 비교할 익숙한 언어는 무엇인가요? (예: Swift)
```

### Step 2 — 설정값 질문

5개 설정을 순서대로 질문한다.

```
1/5 — 익숙한 언어 숙련도
익숙한 언어의 숙련도는? (주니어 / 시니어)
```

```
2/5 — 새 언어 경험 수준
작성 대상 언어의 경험 수준은? (입문 / 기초 / 중급)
```

```
3/5 — 비교 설명 범위
설명할 때 어디까지 비교할까요?
- 문법: 구문 비교만
- 문법+패턴: 설계 패턴, 관용구 포함
- 문법+패턴+생태계: 라이브러리, 도구, 커뮤니티 관례 포함
```

```
4/5 — 설명 시점
언제 비교 설명을 할까요?
- 항상: 코드 작성마다 비교 설명 포함
- 요청 시: 물어볼 때만
```

```
5/5 — 설명 형식
설명 형식은?
- 코드 비교: 양쪽 코드를 나란히
- 텍스트: 산문 설명
- 코드+텍스트: 코드 비교 + 해설
```

### Step 3 — 요약

```
프로필 요약:
  익숙한 언어: Swift (시니어)
  작성 대상: Rust (입문)
  설명 범위: 문법+패턴+생태계
  설명 시점: 항상
  설명 형식: 코드+텍스트

이 프로필의 이름을 정해주세요.
```

### Step 4 — 저장

`profiles/{이름}.md` 파일을 생성한다. learner.md, practitioner.md와 동일한 형식.
이 README의 프리셋 테이블에도 추가한다.

## 설명 시 AI 행동 규칙

### "항상"일 때

- 새로운 코드를 작성하거나 수정할 때마다 비교 설명을 포함한다
- 같은 개념이 반복되면 "이전과 동일" 한 줄로 생략 가능
- 설명은 코드 뒤에 배치한다 (코드 흐름을 끊지 않음)

### "요청 시"일 때

- 유저가 명시적으로 물어볼 때만 설명한다
- "이거 Swift로 치면 뭐야?", "설명해줘" 등의 트리거
- 묻지 않은 코드에 대해 자발적으로 비교 설명하지 않는다
