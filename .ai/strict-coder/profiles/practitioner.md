# practitioner

> 새 언어 기초 이상. 요청할 때만 익숙한 언어와 비교 설명한다.

## 고정값

| 항목 | 값 |
|------|---|
| 익숙한 언어 | (설정 필요) |
| 작성 대상 언어 | (설정 필요) |

## 설정값

| # | 설정 | 값 | 행동 |
|---|------|---|------|
| 1 | 익숙한 언어 숙련도 | 시니어 | 차이점 위주로 비교. 기초 설명 생략 |
| 2 | 새 언어 경험 수준 | 기초 이상 | 기본 문법은 안다고 가정. 고급 패턴이나 관용구만 설명 |
| 3 | 비교 설명 범위 | 문법+패턴 | 구문 + 설계 패턴/관용구까지. 생태계 비교는 생략 |
| 4 | 설명 시점 | 요청 시 | 유저가 물어볼 때만 비교 설명. 자발적 설명 안 함 |
| 5 | 설명 형식 | 코드 비교 | 양쪽 코드만 나란히. 해설은 최소화 |

## 설명 예시

```
// Rust
match result {
    Ok(val) => println!("{val}"),
    Err(e) => eprintln!("{e}"),
}

// Swift 비교
// switch result {
// case .success(let val): print(val)
// case .failure(let e): print(e)
// }
```
