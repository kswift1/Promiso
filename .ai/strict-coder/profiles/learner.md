# learner

> 새 언어 입문자용. 코드 작성 시 항상 익숙한 언어와 비교 설명을 포함한다.

## 고정값

| 항목 | 값 |
|------|---|
| 익숙한 언어 | (설정 필요) |
| 작성 대상 언어 | (설정 필요) |

## 설정값

| # | 설정 | 값 | 행동 |
|---|------|---|------|
| 1 | 익숙한 언어 숙련도 | 주니어 | 기초 개념부터 비교. 고급 패턴은 풀어서 설명 |
| 2 | 새 언어 경험 수준 | 입문 | 기본 문법, 타입 시스템, 에러 처리 등 기초부터 설명 |
| 3 | 비교 설명 범위 | 문법+패턴+생태계 | 구문, 설계 패턴, 라이브러리/도구/관례까지 전부 비교 |
| 4 | 설명 시점 | 항상 | 코드 작성마다 비교 설명 포함. 반복 시 한 줄 생략 가능 |
| 5 | 설명 형식 | 코드+텍스트 | 양쪽 코드 나란히 + 해설 |

## 설명 예시

```
// Rust
let name: String = String::from("hello");

// Swift 비교
// let name: String = "hello"
// Rust는 String 리터럴("")이 &str(참조)이라 String으로 변환이 필요하다.
// Swift는 String 리터럴이 곧 String이라 이 구분이 없다.
```
