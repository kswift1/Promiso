## 효과 측정 기준

### 시간 절약 계산
```
절약 시간 = (수동 예상 시간) - (Skill 실행 시간)

수동 예상 시간:
- Feature 생성: 15분
- 화면 생성: 20분
- PR 리뷰: 10분
- 리뷰 수정: 10분
```

### 성공/실패 기준
- **성공**: Skill이 완료되고 사용자가 결과 승인
- **부분 성공**: 일부 수동 수정 필요
- **실패**: 에러 발생 또는 사용자가 결과 거부
