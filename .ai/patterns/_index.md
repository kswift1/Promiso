# 패턴 저장소 인덱스

> 이 디렉토리는 `skill-suggester` 에이전트가 감지한 반복 패턴을 저장합니다.
> 패턴 분석을 통해 자동화 기회를 발견하고 Skill을 생성합니다.

## 파일 목록

| 파일 | 설명 | 상태 |
|------|------|------|
| [requests.md](./requests.md) | 반복 요청 패턴 | ✅ 초기화됨 |
| [sequences.md](./sequences.md) | 명령어 시퀀스 패턴 | ✅ 초기화됨 |
| [file-creation.md](./file-creation.md) | 파일 생성 패턴 | ✅ 초기화됨 |
| [skill-usage.md](./skill-usage.md) | Skill 사용 통계 | ✅ 초기화됨 |

## 통계 요약

### 현재 상태
- **총 감지된 패턴**: 0개
- **Skill화된 패턴**: 4개 (기존)
- **제안 대기 중**: 0개

### 기존 Skill
| Skill | 대응 패턴 |
|-------|----------|
| /new-feature | Feature 생성 요청 |
| /new-screen | 화면 생성 요청 |
| /review-pr | PR 리뷰 요청 |
| /fix-reviews | 리뷰 수정 요청 |

## 사용 방법

### 패턴 분석 실행
```
"패턴 분석해줘"
"반복 작업 찾아줘"
"Skill 제안해줘"
```

### 자동 트리거
- 동일 요청 3회 이상 반복 시
- "자동화", "반복", "귀찮" 키워드 언급 시

## 관리 지침

- 패턴 파일은 `skill-suggester` 에이전트가 자동 관리
- 수동 편집 시 형식 유지 필요
- 오래된 패턴(90일 미사용)은 아카이브 대상
