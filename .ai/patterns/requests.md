# 반복 요청 패턴

> 사용자의 반복적인 요청 패턴을 추적합니다.
> 3회 이상 반복된 패턴은 Skill 생성 대상입니다.

## 활성 패턴

| ID | 패턴 | 횟수 | 마지막 | Skill 상태 |
|----|------|------|--------|-----------|
| - | (아직 감지된 패턴 없음) | - | - | - |

## 기존 Skill 대응 패턴

| 패턴 | Skill | 비고 |
|------|-------|------|
| "Feature 만들어줘" | /new-feature | ✅ 대응됨 |
| "화면 만들어줘" | /new-screen | ✅ 대응됨 |
| "PR 리뷰해줘" | /review-pr | ✅ 대응됨 |
| "리뷰 수정해줘" | /fix-reviews | ✅ 대응됨 |

## 감지 키워드

### Feature 관련
- "Feature 만들어", "기능 추가", "새 기능"

### 빌드 관련
- "빌드 에러", "컴파일 실패", "빌드 수정"

### 리뷰 관련
- "리뷰해", "검토해", "코드 봐줘"

### 테스트 관련
- "테스트 작성", "테스트 실행", "테스트 추가"

### 배포 관련
- "릴리즈", "버전", "배포"

## 패턴 상세

<!-- 감지된 패턴의 상세 정보가 여기에 추가됩니다 -->

### 템플릿

```markdown
### REQ-{ID}: {패턴명}
- **첫 감지**: {날짜}
- **총 횟수**: {N}회
- **빈도**: 주 {N}회
- **평균 소요 시간**: {N}분
- **제안 Skill**: /{skill-name}
- **예상 절약**: 작업당 {N}분
- **상태**: 🆕 제안됨 / ✅ 생성됨 / ❌ 거부됨
```
