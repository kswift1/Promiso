# v1.3.1

사진 한 장으로 약속을 만들어 보세요.

 • 사진·문자로 일정 만들기
사진이나 문자 메시지를 공유하면 일정을 자동으로 만들어 드립니다. 다른 앱에서 바로 공유할 수도 있습니다.

 • 블록 에디터
일정 설명에 텍스트, 체크리스트, 목록을 자유롭게 조합할 수 있습니다.

 • 도보 경로 안내
약속 장소까지의 도보 경로를 지도에서 확인할 수 있습니다.

 • 알림 개선
푸시 알림에 이미지가 함께 표시되고, 약속이 변경되면 상세한 내용을 알려드립니다.

 • 홈 화면 개선
오늘의 일정 완료 화면과 캘린더 UI를 개선했습니다.
